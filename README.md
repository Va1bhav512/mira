# Mira - Multimodal RAG for Visually Rich PDFs

## Project Phases

| Phase | Focus | Deliverable |
|-------|-------|-------------|
| 0 | Project setup | Code structure, dependencies, CI |
| 1 | PDF processing | Renderer, text extraction, OCR fallback |
| 2 | Visual indexing | ColQwen embeddings, Qdrant setup |
| 3 | Text indexing | BM25 implementation, native text pipeline |
| 4 | Retrieval core | MaxSim, RRF, query-adaptive fusion |
| 5 | Evidence cropping | Heatmaps, spatial aggregation, hi-res crop |
| 6 | Generation | VLM serving, citations, API |
| 7 | Evaluation | ViDoRe/RAGAS benchmarks, ablations |
